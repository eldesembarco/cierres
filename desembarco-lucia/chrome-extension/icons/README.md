# Iconos de la extension

Faltan los archivos de imagen. Por ahora la extension funciona sin ellos
(Chrome muestra un placeholder gris).

Para agregar iconos custom, generá 3 PNGs cuadrados:
- `icon16.png` — 16x16
- `icon48.png` — 48x48
- `icon128.png` — 128x128

Sugerencia visual (consistente con el theme del panel):
- Fondo con gradient gold→ember
- Letra "D" centrada en font Cinzel bold
- Color #1a0f0a (ink) sobre el gradient

Podés generarlos con cualquier herramienta gráfica o servicios online.
Después reemplazá los archivos en esta carpeta.
